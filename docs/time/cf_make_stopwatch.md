# cf_make_stopwatch

GitHub: [cute_time.h](https://github.com/RandyGaul/cute_framework/blob/master/include/cute_time.h)
Records a new `start_time` for a [CF_Stopwatch](/time/cf_stopwatch).

```cpp
CF_Stopwatch cf_make_stopwatch();
```

## Return Value

Returns an initialize [CF_Stopwatch](/time/cf_stopwatch) to the time of _right now_ (e.g. with [cf_get_ticks](/time/cf_get_ticks) internally).

## Remarks

Once created with [cf_make_stopwatch](/time/cf_make_stopwatch) the time elapsed can be fetched. To reset the stopwatch, simply call
[cf_make_stopwatch](/time/cf_make_stopwatch) again and overwrite your old stopwatch. To fetch the time elapsed, call [cf_stopwatch_seconds](/time/cf_stopwatch_seconds),
[cf_stopwatch_milliseconds](/time/cf_stopwatch_milliseconds), or `cf_microseconds`.
