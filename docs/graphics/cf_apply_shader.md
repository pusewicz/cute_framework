# cf_apply_shader

GitHub: [cute_graphics.h](https://github.com/RandyGaul/cute_framework/blob/master/include/cute_graphics.h)
Uses a specific shader + material combo for rendering.

```cpp
void cf_apply_shader(CF_Shader shader, CF_Material material);
```

## Remarks

The [CF_Shader](/graphics/cf_shader) defines how to render a mesh's geometry, set by [cf_apply_mesh](/graphics/cf_apply_mesh). The [CF_Mesh](/graphics/cf_mesh) holds input geometry to the
vertex shader. A [CF_Material](/graphics/cf_material) defines uniform and texture inputs to the shader.
