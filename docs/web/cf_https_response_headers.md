# cf_https_response_headers

GitHub: [cute_https.h](https://github.com/RandyGaul/cute_framework/blob/master/include/cute_https.h)
Returns an array of response headers.

```cpp
htbl const CF_HttpsHeader* cf_https_response_headers(CF_HttpsResponse response);
```

## Remarks

Intended to be used with [cf_https_response_headers_count](/web/cf_https_response_headers_count). Do not free this array, it will
get cleaned up when the originating [CF_HttpsRequest](/web/cf_httpsrequest) is destroyed via [cf_https_destroy](/web/cf_https_destroy).
If you're familiar with [htbl](/hash/htbl) you may treat this pointer as a hashtable key'd by strings.
